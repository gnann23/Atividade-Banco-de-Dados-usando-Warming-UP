Atividade-Banco-de-Dados-usando-Warming-UP

5: Exclusão de vendas canceladas
6: Exclusão de registros inválidos
7: Quantidade de vendas por categoria 
8: Resumo financeiro por categoria
9: Total vendido por vendedor
10: Relatório de vendas por estado
